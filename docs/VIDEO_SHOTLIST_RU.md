# План видеозаписи, 90–120 секунд

1. 0–12 c: проблема групповых платежей, landing page.
2. 12–22 c: сравнение учёта расходов и фактического расчёта; показать статус продукта.
3. 22–30 c: экран Arc Studio с исходным URL и бейдж `Built with Arc Studio`.
4. 30–42 c: создать группу из трёх **разрешённых** адресов; показать метку сети.
5. 42–55 c: расходы, balances, proposal и план ID.
6. 55–68 c: одобрение каждым кошельком, показать транзакции.
7. 68–82 c: точный allowance и USDC funding двумя должниками.
8. 82–94 c: finalization; отдельно creditor withdrawal.
9. 94–108 c: explorer, проверенные receipt/event/balance; явно показать `Arc Testnet`, если mainnet evidence ещё нет.
10. 108–115 c: польза и ссылка на публичное приложение.

Использовать только живые экраны. Скриншоты из `docs/screenshots/` — архивная тестовая демонстрация. Пока mainnet не подтверждён, не озвучивать его как выполненный. Видео ещё **не записано**.
