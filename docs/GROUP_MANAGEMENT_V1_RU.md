# Управление группами V1

Меню каждой группы даёт локальное переименование, описание, архив, скрытие, восстановление, копирование ссылки, экспорт и очистку локальных заметок. Active / Archived / Hidden — фильтры этого браузера. Группа остаётся доступной по ссылке и Group ID; onchain участники, планы, выплаты и история не меняются.

Экспорт V2 содержит chain ID, контракт, Group ID, порядок onchain участников, расходы и локальные настройки. Импорт проверяет эту привязку, структуру расходов, суммы, адреса меток и размер JSON. Старый V1 экспорт импортируется только после отдельного выбора пользователем. Для очистки заметок mainnet Group #1 сначала требуется скачать резервную копию и ввести фразу подтверждения.

`Change members / Create revised group` создаёт отдельный локальный черновик. В нём можно менять адреса и порядок. Расход копируется только если его плательщик и все включённые участники остались в новом составе; остальные расходы перечисляются как пропущенные. Старый план, approvals, USDC и entitlements никогда не переносятся. Если старый план активен, пользователь отдельно подтверждает, что он останется в исходной группе.

Только на отдельной странице `Create new group onchain` после проверки нового состава и оценки комиссии возможна транзакция создания. Перед каждым финансовым действием действуют прежние проверки сети, аккаунта и runtime контракта. Контракт `AtomicCloseout.sol`, ABI финансовых операций, pinned deployment, `/deploy` и Arc Studio provenance не менялись. Независимого аудита контракта нет.
